# 美股趨勢跟蹤策略規則（v1.0）

## 回測工具
- 檔案：`/Users/kochechin/Desktop/google/us_backtest/engine.py`
- 執行：`/opt/homebrew/bin/python3 engine.py backtest --stocks NVDA,AAPL --years 2024 2025`
- 參數設定：`config.py`
- 資料來源：yfinance（auto_adjust=False，使用真實市價）
- 市場基準：S&P 500 (^GSPC)

## 資金管理
| 項目 | 設定 |
|------|------|
| 總資金 | $30,000 USD |
| 單筆風險上限 | 帳戶 1% = $300 |
| 部位計算 | ATR-based：股數 = $300 / (2 × ATR14) |
| 最大同時持倉 | 5 檔 |
| 單檔最大部位 | 帳戶 25% = $7,500 |
| 手續費 | $0（Firstrade 零佣金） |
| 滑價 | 0.05%（單邊） |

## 進場條件（6 項全部同時成立才進場）

1. **量能放大**：當日成交量 > 5日均量
2. **突破 Box 高點**：收盤 > 過去 10日實體最高點
   - `BH = max(Open, Close)`（實體，不用影線）
   - `BoxH = 前10日 BH 最大值`（不含今天）
3. **均線多頭排列**：EMA20 > EMA50 > EMA100
4. **收盤站上趨勢線**：收盤 > EMA50
5. **OBV 向上**：OBV > OBV 10日均線，且 OBV > 10日前的 OBV
6. **相對強度（RS）**：個股 20日漲幅 > S&P 500 20日漲幅

## 部分停利
| 觸發 | 動作 |
|------|------|
| 帳面獲利達 +15% | 賣出持倉 20% |
| 帳面獲利達 +40% | 賣出持倉 50% |

## 出場條件（優先順序由高到低）

```
① ATR 停損        → 價格跌破 ATR trailing stop（進場價 - 2×ATR，隨獲利上移）
② 10% 硬停損      → 帳面虧損 ≤ -10%，全數出場（跳空穿越的最後防線）
③ 跌破趨勢線     → 收盤 < EMA50，全數出場
④ 高檔停利       → 帳面獲利 ≥ 20% + 量放大 + 跌破 EMA20
```

## 加碼條件
- **順勢加碼**：持倉獲利中 + 進場訊號再次觸發 → 追加（總部位不超過帳戶 25%）
- **禁止向下攤平**：虧損部位只能出、不能加

## 與台股版關鍵差異
| 項目 | 台股版 | 美股版 | 原因 |
|------|------|------|------|
| 停損 | -8% 固定 | ATR 動態 + -10% 硬停損 | 美股無漲跌幅限制，需動態調整 |
| 均線 | SMA 5/10/20 | EMA 20/50/100 | 美股趨勢更持久，用 EMA 更平滑 |
| 交易成本 | 0.1425%+0.3% | 0%（零佣金） | Firstrade 零佣金 |
| 部位計算 | 固定 30% 資金 | ATR-based | 依波動度動態調整，控制每筆風險 |
| 急跌出場 | 跌>10%+放量 | 移除（改用 ATR） | 美股波動大容易誤觸 |
| Box 窗口 | 5 日 | 10 日 | 美股需更長確認期 |

## 執行紀律
1. **停損守死**：ATR stop 觸發 → 隔日必出，不重新評估
2. **禁止向下攤平**：虧損部位只出不加
3. **同產業風險控制**：同產業最多 2 檔（你目前 6/10 半導體過度集中）
4. **空手也是持倉**：無訊號期間不進場

# 每日開盤前，念一遍（2026年7月，學費 27 萬）

1. 訊號未亮，我不進場——差一項就是沒亮。（六月起14筆違規，全虧）
2. 沒有佈局、沒有抄底、沒有感覺，只有 8/8。
3. C 級股訊號亮了也不碰。（松翰 1勝7敗、力積電 2勝9敗）
4. 同題材只押一份。（松翰＋盛群，同週雙停損）
5. 13:00 後才買，早盤的突破會騙人。（雙鍵：早盤買356，收盤328）
6. 虧損不攤平，攤平是把錯誤放大。（晶技 -4.8萬）
7. 收盤破 -8%，隔日必出，反彈不是理由。（凹單的代價：單月 -10萬）
8. 漲停買不到就放掉，真行情不缺上車日。（奇鋐的行情走了三個月）
9. 空手也是持倉，掃描器說零，零就是答案。
10. 賺錢的是紀律，不是預測——我的對手不是市場，是昨天的自己。
